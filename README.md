# Настройка PKCE

### Проблема с доступностью keycloak из контейнера api

При запуске приложений через команду `docker compose up -d` и фронтенд, и бэкенд будут обращаться к keycloak через `http://keycloak:8080`, а не `http://localhost:8080`. Чтобы редирект с фронтенда на страницу логина SSO-сервиса проходил успешно, необходимо добавить запись `127.0.0.1 keycloak` в файл `/etc/hosts`.

Изменение адреса keycloak с `localhost` на `keycloak` необходимо для того, чтобы приложение в контейнере api могло успешно к нему обращаться. В то же время если сделать это только на стороне api, валидация JWT-токенов будет падать с ошибкой из-за несовпадения адреса создателя токена и сервиса, который проводит валидацию.
